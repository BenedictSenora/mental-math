Squaring Numbers Ending in 5

Core Arithmetic Module 5 of 6

The Visual Pattern of 5s

Every single number ending in 5, when squared, always ends in 25. You only need to calculate the front digits.

Formula: For a number N5, the answer is [N \times (N + 1)] \mid 25.

3-Step Tutorial

  1. Look at the first digit(s) before the 5.
  2. Multiply that digit by the next higher number (e.g., if it's 3, do 3 \times 4).
  3. Write 25 right after that product.

Tutorial 1: Two-Digit Squares

Multiply the tens digit by itself plus one, then lock in 25 at the end.

Example: 35²

1. First digit is 3. Next higher number is 4.

2. Multiply: 3 × 4 = 12.

3. Attach 25: 1,225.

Tutorial 2: Three-Digit Squares

The exact same pattern works for three-digit numbers—treat the first two digits as one number.

Example: 105²

1. First digits are 10. Next higher number is 11.

2. Multiply: 10 × 11 = 110.

3. Attach 25: 11,025.
